Anaglyfin

Choose which 3D versions Anaglyfin offers for MVC videos, which one a client gets by default, and how much of the server Anaglyfin may spend converting them. Everything on this page is a name from Anaglyfin's own profile list or a number: it accepts no conversion description, no encoder argument and no path.
The version listed first for every client that has no override below. Anaglyfin only offers versions ticked as enabled, so a default that is not ticked is never used.
The version Anaglyfin serves when the default cannot be. The 2D base view plays on every client, which is why it ships as the fallback.

Enabled profiles

The versions a client can pick from. Unticking every one of them is answered with the shipped set rather than with an empty version list.

Device and client defaults

Pin the default for one device or one client, so that a TV driving shutter glasses can start on an anaglyph while a browser starts on side-by-side. An entry that names neither is ignored, and an entry that names both wins over one that names either.

Custom anaglyph colours

Used by the "3D Anaglyph Custom Colours" profile only: each eye is converted to grayscale and tinted with this colour, which is stored as #RRGGBB.
A preset anaglyph - red/cyan, green/magenta, yellow/blue and the rest - is a profile of its own and ignores these two colours.

Conversion limits

Decoding MVC is software work on every supported build, so this is the knob that decides how much of the server Anaglyfin may take. One at a time is the shipped default.
Only the encode stage of an Anaglyfin job is affected. MVC is always decoded in software, and ordinary playback keeps the decode path the server picked.
The Anaglyfin FFmpeg wrapper is started by the server and not by this plugin, so it reads its own setup from the environment the server passes it. These variables are listed as guidance only: this page cannot write them, and a path typed into this page could not reach the wrapper anyway.
ANAGLYFIN_REAL_FFMPEG
The real FFmpeg-mvc binary the wrapper hands commands to. Checked first.
FFMPEG_MVC_PATH
Where the same binary comes from when ANAGLYFIN_REAL_FFMPEG is unset, so a standard FFmpeg-mvc installation needs no second setting. The server's own ffmpeg on PATH is the last resort when neither names it.
ANAGLYFIN_MAX_CONCURRENT_TRANSCODES
The limit the wrapper enforces. Keep it equal to the value saved above: the wrapper starts in the server's environment and cannot read this page.
ANAGLYFIN_LOCK_DIR
The directory the wrapper counts running jobs in. Every wrapper process on the server has to see the same directory, which on a containerised server means a mounted shared one.
