Anaglyfin

Choose the 3D versions Anaglyfin offers and the subtitle depth it asks for. Every field is a bounded choice: a profile, a colour or a number.
Anaglyfin settings are edited from the Jellyfin dashboard.
This copy of the page was opened directly, so it has no signed-in dashboard to ask for the stored settings and nothing to save them back through. Everything below is Anaglyfin's shipped defaults and saving is refused, rather than writing over the server's settings with guesses. Open the page from the dashboard instead: it is listed as Anaglyfin in the dashboard settings menu, and it is reachable from Dashboard -> Plugins -> Anaglyfin as well.
The version offered first to every client. Only enabled versions are offered.

Enabled profiles

The versions a client can pick from.

Custom anaglyph colours

Used by the "3D Anaglyph Custom Colours" profile only, as #RRGGBB.
A preset anaglyph - red/cyan, green/magenta, yellow/blue and the rest - is a profile of its own and ignores these two colours.

Conversion limits

How many Anaglyfin jobs may run at once. One is the shipped default.

Subtitle depth

How far in front of or behind the screen a burned-in subtitle sits. A server whose FFmpeg has no depth support plays captions flat whatever is chosen here.
Automatic reads the depth the disc carries. Flat keeps subtitles on the screen plane. The other two ask for one number each, below.
Positive puts the caption in front of the screen plane, negative behind it.
The authored depth sequence to read directly, 0 to 31.

Deployment

Requires a Jellyfin-compatible FFmpeg-mvc build. In Jellyfin's FFmpeg path, select the Anaglyfin FFmpeg entry point supplied with this plugin. Installation details are in the Anaglyfin documentation.
